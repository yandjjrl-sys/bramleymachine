# Bramley Machine Works Static Website

This is a static website package for `bramleymachine.com`.

## Pages

- `index.html`
- `about.html`
- `products.html`
- `product-detail.html`
- `contact.html`
- `privacy.html`

## Deployment

Upload all files and the complete `assets` folder to GitHub Pages, Cloudflare Pages, or any static host. No build step is required.

Product categories are focused on finished shop equipment, workholding tools, material handling products, and machine maintenance accessories.
