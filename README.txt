BRAMLEY MACHINE WORKS INC. WEBSITE

FILES
- index.html: main one-page company website
- privacy.html: privacy policy
- assets/styles.css: visual styling
- assets/script.js: mobile navigation + footer year
- assets/logo.png: supplied Bramley brand logo
- assets/favicon.png / apple-touch-icon.png: web icons generated from the supplied logo

GITHUB PAGES
1. Upload the contents of this folder to the root of your GitHub repository.
2. Open repository Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select main and /(root), then Save.
5. Test the GitHub Pages URL first.
6. Only after the site works, add bramleymachine.com under Custom domain and update GoDaddy DNS.

IMPORTANT
- Product photos are representative stock images from Pexels and are loaded remotely.
- The website intentionally avoids claims about manufacturing facilities, certifications, years in business, customer counts, or inventory that were not provided.
- The product text is category-level and avoids naming specific goods/materials that could create unnecessary trade-remedy implications.
- Replace the stock photos with your own product photos when available for a more authentic site.
